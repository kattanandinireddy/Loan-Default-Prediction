# Loan Default Prediction
This project predicts whether a loan application will be approved or not using machine learning. The dataset was cleaned, preprocessed, and used to train different 
classification models. Finally, the models were compared to determine which one performed better.

## Technologies Used

Python

Pandas

NumPy

Scikit-learn

XGBoost

Google Colab

## Models Used

Logistic Regression

Random Forest

XGBoost

## Steps Followed

Loaded the dataset

Handled missing values

Encoded categorical columns

Removed unnecessary columns

Scaled numerical features

Split the dataset into training and testing sets

Trained multiple machine learning models

Compared the models using evaluation metrics

Saved the trained model using Joblib

## Evaluation Metrics

Accuracy

Precision

Recall

F1 Score

ROC AUC Score

## Results

The models were compared on the same dataset.

Logistic Regression gave the best overall accuracy and F1 Score.

XGBoost achieved the highest Precision and ROC AUC Score.

Random Forest also performed well with high Recall.
