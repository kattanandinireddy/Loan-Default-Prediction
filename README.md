# Loan Default Prediction
This project predicts loan approval using a Logistic Regression machine learning model.
The project includes handling missing values, encoding categorical features, feature scaling, training a Logistic Regression model, and evaluating its performance on the Loan Approval Prediction dataset.
Test Accuracy: 78.86%
## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab
## Project Files
- "Loan_Default_prediction.ipynb" – Complete notebook containing data preprocessing, model training, and evaluation.
- "loan_default_model.pkl" – Saved trained Logistic Regression model.
## Dataset
Loan Approval Prediction dataset from Kaggle.
